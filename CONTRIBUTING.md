# Contributing

Open issues and pull requests in the repository that owns the package.

Read its README and `AGENTS.md` first. Package-specific instructions take
precedence over these defaults.

- Keep changes focused and follow the existing code.
- Test changed behavior and useful failure cases.
- Update examples when an API changes.
- Run the package's checks. Explain anything you could not run.
- Use [Conventional Commits](https://www.conventionalcommits.org/).

For a new provider or a substantial API change, open an issue with a use case
and a small example before implementing it.

Follow the package's release policy. Do not publish, bump versions, or add
Changesets unless that policy calls for it.

Never include credentials or private data in issues, code, or test fixtures.
