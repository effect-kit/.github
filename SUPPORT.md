# Getting help

Start with the package README and examples.

Ask questions in the package repository's Discussions, if enabled, or open an
issue. Include the package version, Effect version, runtime, and a small example.

Use the issue forms for bugs and feature requests. Remove credentials and private
data from reproductions.

For Effect itself, see the [Effect docs](https://effect.website/docs).

Report vulnerabilities through the [security policy](SECURITY.md).
